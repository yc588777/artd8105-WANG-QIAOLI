# 海棠织序 · 参数化团扇 / HAITANG parametric fan

Session 5 三维作业。网格来自 HAITANG WEAVE LAB（海棠经纬），不是 Blender 手建。Downloads 里的 `fan_parametric -3D design files .stl` 与导出包 `8bbe9a63b573` 的 `fan_parametric.stl` 哈希相同，复制进本目录，原文件仍留在 Downloads。

This is the Session 5 printable object. The mesh was generated by HAITANG WEAVE LAB, not modelled by hand in Blender. The Downloads STL was copied here; the original was left in place.

## 规则 / Rule

外框、双瓣护片、扇柄锁死；变的是框内竹编。当前启用层 L2「主图案」，算法 `rotating-diamond`，preset `rotating-diamond-reference`。经纬在护片与扇柄处连续锚入边框，一次布尔并成单件。

The outer silhouette, two guards and handle stay locked. Only the inner weave changes. Layer L2 uses rotating-diamond. Strips anchor into the rim so the export is one Boolean-unioned piece.

## 参数 / Parameters

完整快照见 `design_parameters.json`。提交这份网格时用的值：

| 参数 | 值 | 作用 |
|---|---|---|
| pattern / preset | diamond / rotating-diamond-reference | 菱形旋转编织 |
| target_height | 180 mm | 扇高 |
| rim_width / rim_depth | 5.8 / 7.0 mm | 边框宽度与厚度 |
| frame_mm | 2.6 mm | 外框截面 |
| strand_width_u / v | 2.75 / 1.6 mm | 经纬带宽 |
| L2 strip_width | 2.6 mm | 主图案条宽 |
| density_u / v | 1.35 / 1.55 | 经纬密度 |
| L2 density | 1.15 | 主层密度 |
| relief / t_max | 2.2 mm | 编织起伏上限 |
| blend_radius | 14 mm | 图案与边框过渡 |
| seed | 5205（层内 7） | 可复现 |
| geometry_lock / print_safe | true | 禁止改外轮廓 |
| L1 / L3 / L4 | disabled | 只印主图案一层 |

## 二次检查 / Independent check

对 `fan_parametric.stl` 跑 `python check_stl.py`（2026-10-18）：

| 项 | 结果 |
|---|---|
| 格式 | binary STL，头 `HAITANG WEAVE LAB parametric fan` |
| 三角形 | 260566，文件尺寸与 `84 + n×50` 一致 |
| SHA-256 | `424e96356e54d4472543807958506d29f988939bc728cb1e4f5e2ac2097beda4` |
| 包围盒 | 约 **114.36 × 180.36 × 7.00 mm**（毫米制，FDM 热床上可平放） |
| 有向体积 | **+33194.65 mm³**（约 33.2 cm³），法线朝外 |
| 最薄处（生成器） | 条带 2.2 mm，边框深度 7.0 mm，均 ≥ 1 mm |
| 壳体（生成器） | 1 件；边界边 0；非流形边 0 |

STL 三角面不共享顶点，按坐标焊接统计边界边会虚高，所以流形结论以生成器网格图为准，体积符号以本脚本为准。生成器把厚度报成 13.05 mm，是起伏与边框的包络算法值；**本文件实测 Z 向是 7.0 mm**，与 `rim_depth` 一致。打印前仍要在切片软件里看一层。

The STL is millimetre-scale, one solid with positive signed volume, walls thicker than 1 mm. Tessellated vertices are not shared, so a weld-based hole count on the STL is not the manifold test; the generator mesh graph reported zero boundary edges and one shell. Slicer preview is still required before FDS booking.
