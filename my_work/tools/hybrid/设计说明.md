## 一、原作是什么

本周呈现的作品是 Bell Labs 的 *Computer Speech*（Kelly & Gerstman，穿孔卡片音素码，约 1961–63）：机器把 *He saw the cat* 念成 *Hee Saw Dhuh Kaet*。

本系统不复原当年的硬件机柜，复原的是**规则**：

1. 文本写成 Kelly–Gerstman 音素卡。
2. 音素卡写成音高、时长。
3. 音高与时长写成声道（TRACT）与共振峰，磁带放音。
4. 默认画面沿用弹窗展同一套可见身体：梭梨甲藻，由蜂群 + 生长 + 反应扩散叠成。

## 二、这套设计系统做什么

和弹窗展《荧光潮汐：蓝眼泪》一样：不是一张成品图，而是一组可执行的规则与参数。观者（或老师）应能：

| | 操作 | 结果 |
|---|---|---|
| **复原原作** | 点 **原作 ORIGINAL** | 默认混成 + 默认歌词 *He saw the cat* → `H—EE—S—AW—DH—UH—K—AE—T`。再按 PLAY TAPE 出声。 |
| **变体：新歌词** | 点 **变体 · Daisy** / **变体 · 他看见猫**，或在 LYRIC 框自写 | 同一套音素规则念另一句。底层规则没换，输入换了。 |
| **变体：随机规则** | 点 **变体 · 随机规则** 或 RANDOM MIX | 层、耦合、参数被改写，画面变成未曾指定的叠加。 |
| **变体：活输入** | 打开 **捕捉动态** | 运动改写全部图层，并改 PITCH / DUR / TRACT。 |

## 四、默认参数（原作配方）

| 参数 | 默认 | 为何 |
|---|---|---|
| 层 | flock + grow + diff | 弹窗展同一套可见身体：个体、生长、化学场。 |
| 耦合 | 轨迹→化学种子；枝尖→注料 | 两层之间有物质交换，不是三张透明贴图。 |
| 歌词 | He saw the cat | 原作句子。 |
| 音素 | H—EE—S—AW—DH—UH—K—AE—T | Kelly–Gerstman 卡片。 |
| 演唱 | ON | 元音走 Daisy 旋律；可关掉只留朗诵。 |
| 语速 | 1 | 卡片默认时长。 |
| 基频 | 120 Hz | 朗诵基频。 |
| 随机视觉 | OFF | 原作是稳定配方，不是持续变形。 |

## 五、English statement

HYBRID.06 is the Session 4 design system. It reconstructs *Computer Speech* as a rule, not as a facsimile of the 1963 machine: a lyric becomes Kelly–Gerstman cards, then pitch, duration and tract. The default picture is the same pyrocystis body used in *Fluorescent Tide*: flock, L-system, Gray–Scott. **ORIGINAL** returns that reconstruction. New lyrics, random-rule wander, and camera motion make other works from the same system. Do not submit `localhost`. Open the GitHub Pages URL above.
