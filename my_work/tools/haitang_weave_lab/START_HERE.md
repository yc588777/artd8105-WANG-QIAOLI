# 海棠织序｜Cursor 启动说明

## 步骤 1
解压本启动包到英文目录，例如 `D:\HAITANG_WEAVE_LAB`，在 Cursor 中执行 `File > Open Folder` 打开整个目录。

## 步骤 2
在 Cursor 的 Agent 模式粘贴：

```
请读取项目根目录中的 HAITANG_PARAMETRIC_FAN_CURSOR_MASTER.md，严格执行全部最高优先级约束。
请首先检查 assets/original/ 中的 obj_2_fan.stl 和 obj_1_handle_logo.stl，复核原始包围盒、单位、原始结构和文字候选区域，确认这是海棠形刚性手扇而非折扇。
现在从 Phase 0 开始实际开发：检查 Blender MCP 连接、检查几何、生成不可变基准和项目骨架，随后实现可运行的网站与局部参数化竹编模型生成。
不要把概念效果图当成果，不要虚构成功测试。无法自动判断文字位置、扇面—扇柄接口时，提供网页内人工确认工具且先保护原模型。
请实际运行程序和模型测试，并报告执行结果。
```

## 步骤 3
如首次运行报错，先只执行环境审计，不需要一次加载全部图像。后续分阶段继续即可。

注意：STL 不带单位，主指令中的数值暂按 mm 候选值，在开发时应进行确认；源 STL 一律保留、不覆盖。
