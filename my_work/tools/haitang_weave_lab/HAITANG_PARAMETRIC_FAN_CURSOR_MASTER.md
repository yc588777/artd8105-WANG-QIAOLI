## 2. 结构语义分区（强制）

首先对扇面进行智能分区，并在网页显示可供确认的蒙版；分区至少为：
- `RIM_LOCKED`：海棠花瓣形外边框与轮廓边缘，完全冻结。
- `CONNECTION_LOCKED`：扇面与扇柄连接处、榫接、孔洞、承力区域，完全冻结。
- `REINFORCEMENT_LOCKED`：不可删除的关键承力筋与框架区域。
- `WEAVE_EDITABLE`：可重新生成竹编纹理的内部区域。
- `OTHER_COMPONENT_REVIEW`：小型离散连通片/不明结构，默认保留、等待确认。

保护区必须从原始三维网格真实提取，不得靠一个简单矩形覆盖来近似海棠轮廓。如果无法自动高置信度识别连接位置和需要保留的实体框架，显示三维手工蒙版编辑（画笔、橡皮擦、边界点、锁定区域），并等待用户确认，再进行破坏性布尔运算。

锁定区域采用原始顶点与三角形的复制或可靠的无损局部保存。允许在接合边缘做最小限度、可检验的桥接/布尔修复，但不得修改受保护区域的外表面和边界尺寸。

## 4. 参数化竹编纹样计算引擎

### 4.1 图案策略
从中国传统竹编的经纬编织逻辑出发，实现由几何参数驱动、3D 打印可成型的镂空结构：
- `PlainWeave`：基础经纬交错竹编。
- `TwillWeave`：斜纹错位竹编。
- `WaveWeave`：连续曲线、波浪编织。
- `CellularWeave`：蜂窝/生长式交错网格。
- `GradientWeave`：渐变密度与粗细。
- `CustomEquation`：可控频率/相位/振幅的参数式纹样。
可选添加以 Gyroid / Voronoi 为灵感的风格，但不得错误声称任意二维花纹就是真实 TPMS 三维结构。

### 4.2 真实生成方法
以扇面局部二维参数坐标 (u,v) 建立经纬纤维中心线：
- 经向间距 `pitch_u(u,v)` 与纬向间距 `pitch_v(u,v)` 由分区密度场决定；
- 纤维实体宽度 `strand_width_u/v(u,v)` 由分区粗细场决定；
- 单元纵横比、局部波幅、波长/重复数量与位置由 `cell_aspect_ratio`、`wave_amplitude`、`frequency` 决定；
- 经纬交点上下交错由 `over_under_phase`、`interlace_period` 和局部相位控制；
- 高矮解释为**局部编织起伏高度与单元纵横比例**；不得改变原海棠扇面的整体高度及固定外轮廓。

使用 Curve/Sweep/Geometry Nodes 或 Python 实体建模，将经纬纤维构造成实体几何并通过受保护边界裁切。不能只显示贴图或者输出悬空曲线。对于每个交叉点，检查间隙、最小实体厚度、成型方向、交错路径的结构连续性。

注意**扇面原有厚度外包络为 2mm**：默认将所有纹样几何严格控制在源模型 Z 区间和边界之内。若编织物理穿插所需真实上下跨越超过 2mm，首先采用 2.5D 起伏浮雕或同层一体化交错表达；禁止悄悄增加厚度或突破用户“尺寸不变”的要求。可在高级选项中提出额外厚度版本，但必须由用户明确开启，默认不可用。

### 4.3 分区独立编辑
必须支持至少两种分区系统：
A. 结构化分区：上/中/下 × 左/中/右共九区（按海棠形自由轮廓归一化裁切，而非简单矩形实体覆盖）。
B. 自由画笔分区：用户可以直接在扇面三维/二维投影视图中绘制多边形、径向渐变蒙版和画笔区域，保存成区域配置。

每一区单独可调：
- 纵向密度 density_u / 横向密度 density_v；
- 经向宽度 strand_width_u / 纬向宽度 strand_width_v；
- 起伏高度 relief_height；
- 单元高宽比 cell_aspect_ratio；
- 交错相位 stagger / offset_x / offset_y；
- 编织角 weave_angle、纹样频率 frequency、波浪幅度 amplitude；
- 随机扰动 randomness 和可复现的 seed；
- 分区间平滑过渡半径 blend_radius；
- 区域启用/禁用、锁定、复制参数、恢复默认。

分区过渡采用连续插值或加权混合，不能在边界产生断丝、台阶、自交和悬浮孤岛。用户调节任意一项后，所有其他冻结结构原样保存。

### 4.4 约束与有效参数
创建 `ParametricConstraints`，默认适配常见 FDM 打印的候选参数范围，不能把经验值当作通用认证值。每次改变纹样必须实时检测：
- 最细实体线宽、桥接条件、孤立悬空组件、流形、法线、负体积、自交与穿透。
- 内部纹样和外圈/连接处的粘接与连续性。
- 源 Z 厚度外包络、源 XY 外轮廓、锁定装配接口是否变化。
- 打印设备具体的喷嘴、材料、设备校准数据是否满足当前纹样最小特征。
当参数非法时：显示冲突位置（红色高亮）、问题数值和建议修正按钮；不能导出误标为“可打印通过”的文件。

## 6. 几何锁定的自动验收

使用保存的 Baseline 模型建立自动化测试：
1. 原扇面未编辑外轮廓的 XY 包围盒不得改变。要求尺寸同源值一致（优先保留原始外轮廓三角片）；报告浮点差异。
2. 原扇面 Z 外包络保持 [0,2]（确认单位后按 mm）。
3. 扇柄去字前后 AABB 与非文字区域保持不变；对非文字区运行逐面/点对面最近距离或 Hausdorff 近似距离校验。作为初始候选，偏差目标 ≤ 0.05mm，最终依据原网格精度调整并报告。
4. 连接结构孔位、轮廓、厚度和装配参考面必须维持不变；建立命名特征与偏差对比；绝不能把“整体长宽高不变”当作所有接口都不变的证明。
5. 源文件中不明的小连通体不得丢失；如无法分类，标记为需人工确认。
6. 网格至少通过边界、非流形、法线、自交、孤立体、厚度与单位检查；源模型已有缺陷须分开报告。尽可能输出 watertight 单个实体或明确多组件结构。
7. 生成后保存 `geometry_comparison.json`、`mesh_validation.json` 与可查看的差异截图。
8. 真正的“可打印”声明必须区分数字验证、切片器验证和实体实测状态，不能跨越未做的验证。
